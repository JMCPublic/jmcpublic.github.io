# Aperture 2

Guess everyday objects through small viewpoints, against the clock.

**Play:** open `index.html` in any browser, or use the GitHub Pages link for this repository.

## How it plays
- Five objects a day. Everyone gets the same five, so you can compare times.
- Each object has six 20-second stages (2 minutes). Every 20 seconds a free viewpoint opens in **A** and more of the negative in **B** fills in.
- Help costs 15 seconds each: a new viewpoint, fewer words (10 wrong words go), or a vowel (every copy of that vowel drops into your answer).
- Tap the right word in **C** or type the letters. A wrong answer adds 15 seconds. Not solved in 2 minutes counts as 2:00 plus 30 seconds.
- Your time is shown with penalties in brackets, e.g. `6:42 (1:15)`.

## Files
- `index.html` contains the whole game (HTML, CSS and JavaScript in one file).
